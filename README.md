# Window Pinner

Утилита для Windows, которая позволяет закреплять любое открытое окно поверх остальных и менять его прозрачность


## Запуск

Запустите `start.cmd`. Для работы нужен Python 3 с Tkinter, который входит в стандартную установку Python для Windows.

Если готовая сборка уже создана, можно запускать `dist\WindowPinner.exe`. Python для нее не нужен.

## Сборка EXE

Откройте PowerShell в папке проекта и выполните:

```powershell
.\build.ps1
```

Скрипт создаст отдельное окружение для сборки и положит готовый файл в `dist\WindowPinner.exe`.

## Примечания

Некоторые системные окна и приложения, запущенные от имени администратора, могут не разрешить управление из обычного процесса. В таком случае запустите Window Pinner от имени администратора.

Настройка «Восстанавливать окна при выходе» возвращает исходное закрепление и стиль прозрачности у всех окон, измененных в текущем сеансе.
